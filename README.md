# Daniel Banidolati

I build and fix automations through [LoopMatic](https://loopmatic.io/), with a focus on Make.com, webhooks, and CRM handoffs.

If leads go missing, duplicates appear, or nobody knows whether a write went through, I build a small test that reproduces the problem, fix the workflow, and document what happens when something fails.

## Selected work

- **[LeadFlow](https://github.com/danielbanidolati/leadflow-automation-demo)** — Make.com lead intake with validation, replay protection, and a Google Sheets handoff.
- **[Gumroad → Airtable](https://loopmatic.io/demos/gumroad-airtable/)** — interactive demo of a sale saved once, a replay that adds nothing, and a failed write you can see.

Both are independent demos using synthetic data.
